# Data Dictionary & Codebook Mapping

This directory maintains variable mappings, schema definitions, and statistical classifications for authoritative data ingested into Rural Enterprise Advisor.

## Directory Structure
- `aidis_schema.json`: Mapping of NSS 77th Round (Schedule 18.2) survey microdata fields to application statistical entities.
- `nabard_schema.json`: Normalization rules for converting NABARD unit-cost tables to `NABARDBenchmark` models.
- `scheme_policy_schema.json`: Validation schemas for official government scheme parameters (`PolicyRule`).
